SCORES PHONE — Android-проект

Исходный проект Android-приложения: Игра 25, Игра 33, сохранённые игры и таблица лидеров. Данные хранятся локально в SQLite на телефоне.

Сборка APK выполняется автоматически через GitHub Actions. Откройте Actions → Build Android APK → Run workflow. После успешной сборки скачайте artifact ScoresPhone-debug-apk, распакуйте его и установите app-debug.apk.
